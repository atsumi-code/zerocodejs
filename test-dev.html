エンジニア向け管理画面（zcode-editor）

全機能: ページ編集＋パーツ管理・画像管理・データビューア

このデモで試せること
  1. 「ページ管理」タブでクリック編集・追加・並べ替えを体験
  2. 「パーツ管理」タブでテンプレート記法（{$title:見出し} など）を編集し、プレビューに反映されるのを確認
  3. 「データビューア」タブで保存される JSON / 公開 HTML を確認

データはお使いのブラウザにのみ保存されます。「リセット」で初期状態に戻せます。
