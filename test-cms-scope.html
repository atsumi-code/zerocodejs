page-id 切替で、専用画像の「全ページ / このページ」を確認できます

検証手順

ストレージ ID は test-cms-scope 固定です（通常の test-cms とは別データ）。 images-special プールは page-id を切り替えても共有されます。

  1. 記事 A を選び、画像フィールドから「専用画像を追加」する
  2. 記事 B に切り替え、画像選択モーダルで A 専用画像が出ないことを確認
  3. 記事 B でも専用画像を追加し、保存後に下の JSON で scope / pageId を確認
page-id:
images.special（モーダル表示対象）
